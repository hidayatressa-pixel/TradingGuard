# TradingGuard V0.9 — Execution Revalidation Specification

## Purpose

A Risk Guard ALLOW at signal time is not permanent permission. Paper entry executes on the next candle OPEN, so price movement, entry slippage, and transaction costs can make the original proposal stale.

## Locked rules

1. The Paper account `realized_equity` is authoritative sizing equity. Caller-provided equity must not override it.
2. Signal-time sizing is a proposal only. Before next-open execution, TradingGuard must recompute planned risk using the actual effective entry price after configured adverse entry slippage.
3. The authoritative stop remains fixed for this proposal. If the stop is no longer below effective entry, cancel/fail closed.
4. Revalidation must use the exact authoritative quantity proposed by Risk Sizing. It must not silently resize quantity at execution.
5. Planned all-in loss for the execution gate includes:
   - price loss from effective entry to stop;
   - entry transaction fee at effective entry;
   - estimated stop exit transaction fee at the stop price;
   - configured adverse exit slippage applied to the stop before estimating exit fee and stop proceeds.
6. Gap-through-stop risk cannot be bounded by this calculation. UI/documentation must state that actual loss can exceed planned risk during gaps.
7. Convert planned all-in loss to `risk_per_trade_pct` using authoritative current Paper realized equity, then rebuild the complete authoritative RiskContext and rerun Risk Guard.
8. Only a fresh `ALLOW` may execute. WARNING, BLOCK, unavailable context, non-finite data, insufficient cash, stale equity, or invalid stop cancels/fails closed.
9. Exit/reduce-risk actions never require a new entry ALLOW.
10. No live broker execution is introduced.

## Planned all-in risk calculation (long-only Paper)

Given quantity `q`, effective entry `E`, stop `S`, fee rate `f`, and adverse exit slippage rate `s`:

- estimated stop fill `X = S * (1 - s)`
- price loss `L_price = q * (E - X)`
- entry fee `F_entry = q * E * f`
- estimated exit fee `F_exit = q * X * f`
- planned all-in loss `L = L_price + F_entry + F_exit`
- execution risk percent `R = L / authoritative_equity * 100`

All values must be finite and positive where applicable. This is a conservative planned-risk estimate, not a guarantee against gap loss.

## Activation gate

Public/UI Auto Paper BUY remains disabled until implementation tests prove next-open revalidation, fresh Risk Guard evaluation, cancellation behavior, and V0.7/V0.9 regression safety.
