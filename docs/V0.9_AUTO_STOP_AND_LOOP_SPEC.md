# V0.9 Auto Stop Loss + Auto Paper Interlock

## Goal
Remove manual Stop Loss as a dependency of autonomous PAPER entry without weakening Risk Guard.

## Authority chain
Authoritative OHLC candles -> indicators -> strategy -> automatic stop -> risk sizing -> prospective Risk Guard -> pending sized entry -> next-event execution revalidation.

## Auto stop rule (long only)
- ATR: 14 completed candles.
- Structure: lowest low of the latest 10 completed candles.
- Stop: structure low - (0.5 * ATR).
- Risk budget never moves the technical stop.
- Invalid/missing/non-positive/out-of-alignment data fails closed.

## Autonomous cycle
`AutoPaperLoopService.cycle()` performs one deterministic evaluation cycle. It does **not** create a background thread or broker order. A future scheduler may call the cycle only when a new authoritative candle is available.

## Interlocks
1. Paper account must be active.
2. Account must be flat with no pending action.
3. Strategy data must be ready and BULLISH/STRONG_BULLISH.
4. Automatic stop must be valid below reference entry.
5. Risk sizing must produce a bounded quantity.
6. Risk Guard must establish ALLOW.
7. Entry remains pending until existing next-event execution revalidation passes.
8. Any failed gate means no new trade.

## Safety boundary
This remains PAPER-only. No broker credentials, live execution, leverage, shorting, or real-money path is added.
